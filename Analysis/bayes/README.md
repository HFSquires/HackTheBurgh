# Analysis/bayes/

Output of `bayes.py` (repository root, task T17): the October 2026 backtest of the Bayesian monthly-budget model of daily discretionary spending, fitted on August and September of the 100 mock statements with person-level cross-validated priors. `intervals_october.csv` has one row per persona, model (`budget`: phi fitted; `iid`: independent days, phi = 1) and horizon (cumulative October spending on days 1 to 7, 14, 21, 28, 31): actual value, predictive mean, the 50 %, 80 % and 95 % central predictive intervals and whether each covered the actual value. `shortfall_october.csv` has one row per persona, price (GBP 50, 300, 1,200 on 1 October) and plan (pay now, pay-in-3): the window to the day before payday, the cushion, predicted discretionary spending, the predicted probability of going below zero and the actual lowest balance. `bayes_summary.md` gives the hyperparameters, the comparison of the point forecast with T12's, and the shortfall Brier scores and reliability tables. Written by code; never edit by hand. Regenerate with `.venv\Scripts\python -X utf8 bayes.py`.
